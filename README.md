## Repository Structure

- `force-app/`: Salesforce DX source code and Apex metadata retrieved from the target org.
- `manifest/`: Project manifest (`package.xml`) defining retrieved metadata components.
- `docs/`: Module documentation, onboarding guides, and retrieval logs.
